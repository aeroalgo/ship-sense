# Style guide — ShipSense UI

- ISA-101: тёмные нейтрали; цвет только при отклонении.
- Читаемость с 2–3 м; крупные touch-таргеты.
- Освещение: `data-theme` = day / night / dim (навсегда).
- Preview skins: `data-design` = d01…d05 — см. `front/creative/v1-p1-screens/CR-UI-01-tokens.md`; после утверждения — один skin.
- Default preview: d01 Bridge Console.
- Запрет слова AI в UI.
- Состояния: loading, empty, error, stale, partial/quarantine.
- Нет квитирования в нашем UI.
- Печать: print-CSS + плашка достоверности где указано в ТЗ.
- Шрифты: IBM Plex / Source Sans 3 / JetBrains Mono / Barlow — не Inter.
