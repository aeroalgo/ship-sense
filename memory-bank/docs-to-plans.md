## 4. Правила load (чтобы не раздувать контекст)

1. **Один DECOMPOSE = один plan** + секции ТЗ из матрицы выше (не весь docx).  
2. РД `.docx` — **таблица сигналов** (KKS/имя/тип), не весь том.  
3. PDF — **только** когда шаг про топологию/мнемо/два узла; не OCR всего файла.  
4. `ТЗ-разработка.docx` без графика — **не** читать параллельно с график-работ.  
5. Решения уже в plan / `systemPatterns.md` / протокол чата — **не** пересказывать из ТЗ.
